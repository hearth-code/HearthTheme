# HearthCode for Chrome

Generated by `scripts/generate-chrome-themes.mjs` from the same color source as the
editor themes. Do not hand-edit the manifests; run `pnpm run sync`.

Each folder is one Chrome theme (Chrome themes do not follow the system light/dark
setting, so Dark and Light ship separately):

- `hearthcode-moss-dark`, `hearthcode-moss-light`
- `hearthcode-ember-dark`, `hearthcode-ember-light`

## Try it locally

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick one of the folders above.
3. To switch back, open `chrome://settings/appearance` and click **Reset to default**.
