# HearthCode for Telegram

Generated by `scripts/generate-telegram-themes.mjs` from the same color source as the
editor themes. Do not hand-edit these files; run `pnpm run sync`.

Every theme ships in Dark and Light for both Moss and Ember. All clients share one
chat palette: quiet shell surfaces, the scheme accent for unread badges and links,
and outgoing bubbles tinted with the accent.

## Telegram Desktop (Windows, macOS, Linux)

Files: `desktop/hearthcode-{moss,ember}-{dark,light}.tdesktop-theme`

1. Send the file to any chat (Saved Messages works well).
2. Click the file in Telegram Desktop, then click **Apply This Theme**.
3. To switch back: **Settings → Chat Settings → Choose from list**.

## Telegram for iPhone and iPad

Files: `ios/hearthcode-{moss,ember}-{dark,light}.tgios-theme`

1. Send the file to Saved Messages (from Telegram Desktop or the Files app).
2. Tap the file in the chat on your iPhone, then tap **Apply**.
3. To switch back: **Settings → Appearance** and pick another theme.

Keys a theme does not set fall back to Telegram's built-in Night (dark) or Day
(light) theme, so new Telegram versions keep working.
